# すきま脳トレ箱

ナンプレ・オセロ・スリザーリンク・坂道チャリ・糸通し・ピクロス・間違い探し・ドット育成・カードバトルの9つが入った、スマホ向けの暇つぶしゲーム集です。
インストール不要で、ブラウザで開くだけで遊べます。

**▶ 遊ぶ：https://saronisi652closer-ship-it.github.io/Easy-games/**

## 入っているゲーム

| ゲーム | 内容 |
| --- | --- |
| ナンプレ | 9×9。かんたん・ふつう・むずかしいの3段階。メモ・戻す・ヒント付き |
| オセロ | CPU対戦。強さはよわい・ふつう・つよいの3段階。「待った」で1手戻せる |
| スリザーリンク | 5×5〜7×7。答えが1つに決まる問題を毎回自動で作る |
| 坂道チャリ | タップでジャンプ、空中でもう1回。穴と岩をよけて距離を伸ばす |
| 糸通し | 押して上がる・離して下がる操作で、流れてくる針の穴に糸を通す |
| ピクロス | 数字をヒントにマスを塗る。絵の問題8問＋自動生成（5×5〜15×15） |
| 間違い探し | 町・海・部屋の絵を毎回自動で作り、違う所を探す |
| ドット育成 | タマゴから1〜2週間かけて育てる育成ゲーム。進化先は13種類 |
| カードバトル（試作版） | マナを使ってモンスターを召喚し、CPUと1対1で対戦。ライフ4000 |

## 特長

- ホーム画面に追加すると、アプリのように起動できます
- 一度開けば、電波がなくても遊べます
- 記録と途中経過は、遊んでいる端末のブラウザに保存されます（サーバーには送りません）
- ライト／ダークモードに対応しています

## 自分のGitHubで公開する

1. このリポジトリを Fork するか、ファイル一式を自分の新しいリポジトリにアップロードする
2. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. main ブランチに push すると自動で公開されます（Actions タブで進み具合を確認できます）
4. 公開URL：`https://<ユーザー名>.github.io/<リポジトリ名>/`

Actions を使わない場合は、Source を **Deploy from a branch**（main / root）にしても公開できます。

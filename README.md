# すきま脳トレ箱

スマホで遊べる暇つぶしゲーム集です。インストール不要で、ブラウザで開くだけで遊べます。

**▶ 遊ぶ：https://saronisi652closer-ship-it.github.io/Easy-games/**

## 入っているゲーム

| 分類 | ゲーム | 途中保存 |
| --- | --- | --- |
| 頭脳 | ナンプレ・ピクロス・スリザーリンク・オセロ | 何問でも同時に途中保存。一覧から再開・やり直し・削除 |
| 頭脳 | 間違い探し | なし（数分で終わる） |
| アクション | 坂道チャリ・糸通し | ハイスコアのみ |
| そのほか | ドット育成・エビワラージャンケン・カードバトル（試作版） | 育成は自動保存、対戦は記録のみ |

## 保存について

- データは遊んでいる端末のブラウザ（IndexedDB）に保存されます。サーバーには送りません
- 以前の版（localStorage）のデータは、初めて開いたときに自動で引き継ぎます。元のデータは消さずに残します
- ホームの「データ」から、全データをファイルやコードに書き出し・読み込みできます

## ファイル構成

| パス | 役割 |
| --- | --- |
| `index.html` | ホーム（つづきから・途中の問題・お気に入り・カテゴリ別一覧） |
| `games/*.html` | 各ゲーム（1ゲーム1ファイル） |
| `common/base.css` | 共通の見た目 |
| `common/save.js` | 保存の仕組み（IndexedDB・旧データ移行・バックアップ） |
| `common/ui.js` | 共通部品（保存一覧の画面など） |
| `common/sfx.js` | 効果音（ファイルを使わずその場で合成） |
| `sw.js` | オフライン用（ネット優先、つながらない時は保存済みを使う） |
| `picross.html` ほか | 以前のURLから新しい場所へ転送するためのファイル |

## 新しいゲームを足すとき

1. `games/` にHTMLを1つ追加（`common/` の3ファイルを読み込む）
2. `index.html` の `GAMES` に1行追加
3. `sw.js` の `FILES` に追加し、`CACHE` の番号を上げる
